GlassChat 部署指南

长期免费托管 · 全球可访问 · 支持通话功能

前提条件：所有平台都需要先将代码上传到 GitHub。请先按下方"第一步"注册 GitHub 并上传代码。
第一步：上传代码到 GitHub
用手机浏览器打开 github.com/signup，注册一个免费账号
登录后，点击右上角 "+" → "New repository"
仓库名填 glasschat，选择 Public，点击 "Create repository"
在仓库页面点击 "uploading an existing file" 链接
将以下所有文件拖入或选择上传（保留目录结构）：
package.json server.js Dockerfile render.yaml railway.json fly.toml .gitignore
以及 public/ 文件夹（含 index.html、css/style.css、js/app.js）
点击 "Commit changes" 提交

提示：手机上传文件夹不方便的话，可以用 GitHub 手机 App 操作，或用电脑操作这一步。

第二步：选择部署平台（推荐 Render）
最推荐

Render

免费套餐永久可用，支持 WebSocket，部署最简单

✓ 免费永久托管

✓ 自动 HTTPS

✓ 从 GitHub 自动部署

打开 render.com，用 GitHub 账号登录
点击 "New +" → "Web Service"
选择你刚创建的 glasschat 仓库
配置：
• Name: glasschat
• Runtime: Node
• Build Command: npm install
• Start Command: node server.js
选择 Free 套餐，点击 "Create Web Service"
等待 2-3 分钟构建完成，获得公网链接
如 https://glasschat.onrender.com
前往 Render
简单

Railway

一键部署，每月 $5 免费额度，速度更快

✓ 一键从 GitHub 部署

✓ 自动识别 Dockerfile

✓ 全球 CDN 加速

打开 railway.app，用 GitHub 登录
点击 "New Project" → "Deploy from GitHub repo"
选择 glasschat 仓库
Railway 会自动识别 railway.json 和 Dockerfile
点击 "Deploy"，等待构建完成
在 Settings 中生成域名
如 glasschat.up.railway.app
前往 Railway

Fly.io

全球边缘节点，免费 3 个小型 VM

✓ 3 个免费共享 CPU VM

✓ 全球节点低延迟

✓ 支持 WebSocket

打开 fly.io 注册账号
需要安装 flyctl CLI 工具（电脑端操作）
运行 fly launch 自动部署
运行 fly deploy 发布

需要命令行操作，建议用电脑

Vercel

不适用 - 不支持 WebSocket

✗ Vercel 是 Serverless 平台，不支持长连接 WebSocket，无法用于本项目。

Railway $5/月额度 ✓ 支持 ✓ 可操作
Fly.io 3 个免费 VM ✓ 支持 ✗ 需电脑
注意事项

• Render 免费套餐：15 分钟无访问会休眠，再次访问时自动唤醒（约 30 秒延迟）。如果需要常驻运行，可升级到付费套餐（$7/月）。

• WebRTC 通话需要 HTTPS 环境，以上平台均自动提供 HTTPS 证书。

• 通话连接受 P2P 限制，部分网络环境可能需要 TURN 服务器（可后续添加）。

• 建议优先选择 Render，手机浏览器即可完成全部操作。

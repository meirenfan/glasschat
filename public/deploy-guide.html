GlassChat 一键部署指南

从代码到 APP，全部免费，约 15 分钟完成

1
获取源码（已完成）

你的代码已托管在 GitHub，这是所有后续步骤的基础。

打开 GitHub 仓库
2
部署到 Railway（已完成）

网站已部署在 Railway，每次推送到 GitHub 会自动更新。

Railway 控制台
每次你修改代码并推送到 GitHub 后，Railway 会自动重新部署，1-2 分钟后网站就是最新版。
3
生成 Android APK 安装包

用 PWA Builder 把你的网站打包成 Android 安装包，完全免费。

打开 PWA Builder

操作步骤：

  • 打开 PWA Builder，输入你的 Railway 网站地址
  • 点击 Start，等待检测完成
  • 点击 Android 选项卡
  • 点击 Generate Package 生成安装包
  • 下载 ZIP 文件，里面有现成的 APK
  • 把 APK 传到手机，安装即可
安装 APK 时手机会提示"未知来源"，允许安装即可。这是正常的，因为你没有上架应用商店。
4
手机安装使用

两种安装方式任选其一：

方式 A：安装 APK（推荐）

把步骤 3 下载的 APK 传到手机 → 点击安装 → 桌面出现 GlassChat 图标。

方式 B：浏览器添加到主屏幕（最快）

手机浏览器打开你的 Railway 网站地址 → 浏览器菜单 → 添加到主屏幕 → 桌面出现图标。

两种方式效果一样：全屏运行、有独立图标、无浏览器地址栏。
5
后续如何更新？

更新代码 → 自动生效，无需重装 APK。

  • 你修改代码 → 推送到 GitHub
  • Railway 自动重新部署（1-2 分钟）
  • 用户打开 APP 时，Service Worker 自动检测更新
  • 提示"应用已更新"，刷新即可加载最新版
只有在修改了 APP 图标或名称等原生配置时，才需要重新用 PWA Builder 生成 APK。普通功能更新完全不需要。
